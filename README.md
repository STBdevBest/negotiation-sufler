# Negotiation Sufler

AI-ассистент для деловых переговоров на очках Even G1/G2.

## Возможности

- **Распознавание русской речи** — Vosk WASM, полностью локально без интернета
- **ИИ-подсказки** — YandexGPT (Яндекс Cloud), бесплатный тир
- **Вывод на HUD** — текстовые подсказки прямо на дисплее очков
- **Режим суфлёра** — краткие советы в реальном времени

## Быстрый старт

### 1. Получите ключи Yandex Cloud

1. Зайдите на https://console.yandex.cloud
2. Войдите через Яндекс-аккаунт
3. Создайте облачную папку
4. Перейдите в **AI Studio** → **API-ключи** → **Создать ключ**
5. Скопируйте **API ключ** и **ID папки**

### 2. Запустите прокси

Прокси нужен чтобы обойти CORS-ограничения WebView. Запускается одной командой:

```bash
# Windows:
start-proxy.bat

# Или вручную:
node proxy/server.js
```

Прокси покажет адрес вида `http://192.168.1.100:3000` — скопируйте его.

### 3. Настройте приложение

1. Запустите приложение на очках
2. В поле **API ключ** вставьте ключ из Яндекс Cloud
3. В поле **Folder ID** вставьте ID папки
4. В поле **URL прокси** вставьте адрес прокси (из шага 2)
5. Нажмите **Сохранить**

### 4. Готово!

Начните говорить — текст распознаётся, ИИ анализирует и даёт подсказки.

## Архитектура

```
Glasses (микрофоны) → Bluetooth → Phone WebView
  → Vosk WASM (STT) → Proxy → YandexGPT (LLM) → HUD
```

- **STT**: Vosk WASM работает локально на телефоне в WebView
- **LLM**: YandexGPT через CORS-прокси (запускается на компьютере в той же WiFi)
- **HUD**: Три панели — статус, транскрипт, подсказка

## Решение проблем

| Проблема | Решение |
|----------|---------|
| "STT: ошибка" | Проверьте подключение к интернету (для скачивания модели) |
| "LLM: не настроен" | Введите API ключ и Folder ID |
| "LLM: ошибка" | Запустите прокси: `start-proxy.bat` |
| Прокси не виден | Проверьте что компьютер и телефон в одной WiFi сети |
| CORS ошибка | Убедитесь что прокси запущен и URL правильный |
| Текст не отображается | Проверьте Bluetooth подключение |

## Получение ключей Yandex Cloud (подробно)

1. Откройте https://console.yandex.cloud
2. Нажмите "Войти" → авторизуйтесь через Яндекс
3. Нажмите "Создать облачную папку"
4. Введите название, нажмите "Создать"
5. В левом меню выберите "AI Studio"
6. Перейдите в "API-ключи"
7. Нажмите "Создать API-ключ"
8. Скопируйте API ключ (показывается только один раз!)
9. ID папки виден в URL: console.yandex.cloud/folders/**b1XXXXXX**
